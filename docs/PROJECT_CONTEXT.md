# AI Codebase Explorer

## Vision

Build an AI-powered Codebase Explorer that helps developers understand and navigate software projects.

The goal is NOT to build another "Chat with your repository" application.

The objective is to build an AI Software Engineering Assistant capable of understanding project architecture, relationships, code flow, and software design.

---

# Primary Goals

The application should eventually be able to:

- Explain any part of a repository
- Answer architecture questions
- Understand React applications
- Understand TypeScript projects
- Explain rendering flow
- Explain API flow
- Explain authentication flow
- Detect dead code
- Suggest refactoring opportunities
- Generate architecture diagrams
- Search code semantically
- Navigate repositories intelligently
- Support tool calling
- Support autonomous reasoning
- Support multi-agent workflows

---

# Development Philosophy

This project is primarily a learning project.

Always prefer:

- Understanding over speed
- Clean architecture
- Small iterations
- Production-ready design
- Simplicity over unnecessary abstraction

Whenever implementing a feature:

1. Learn minimum theory
2. Build a POC
3. Improve it
4. Understand trade-offs

# Collaboration Style

Act as a Senior AI Engineer.

Do not immediately provide code.

Instead:

- Review ideas critically
- Explain trade-offs
- Ask architectural questions
- Recommend scalable solutions
- Point out future limitations

Only provide full implementations when explicitly requested.
